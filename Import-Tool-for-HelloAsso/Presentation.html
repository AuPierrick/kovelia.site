    Gratuit · Extension Google Sheets

    Vos données HelloAsso, proprement rangées dans Google Sheets.

    Import Tool for HelloAsso se connecte à l'API HelloAsso et importe vos inscriptions, présences et paiements directement dans votre feuille de calcul — sans export manuel, sans copier-coller.

    Voir la documentation Une question ? Contactez-moi

    Fonctionnalités

    Ce que l'extension permet de faire

    • Import de formulaires HelloAssoRécupérez les données d'un ou plusieurs formulaires directement dans votre feuille.
    • Actualisation des donnéesRemettez à jour une feuille déjà importée sans tout réimporter à la main.
    • Transformation et mise en formeLes données sont organisées et normalisées automatiquement à l'écriture.
    • Import des présencesSuivez les présences à vos événements en les comparant aux inscriptions.
    • Journaux d'exécutionConsultez ce qui a été importé et repérez rapidement une éventuelle erreur.
    • Sélection et filtrageChoisissez précisément les formulaires et les champs à importer.

    Fonctionnement

    Comment ça marche

    1. Connectez votre compte HelloAsso

      Renseignez le Client ID et le Client Secret de votre organisation, disponibles depuis votre espace HelloAsso.

    2. Choisissez ce que vous voulez importer

      Sélectionnez le ou les formulaires concernés, ainsi que le type de données à récupérer.

    3. Lancez l'import

      L'extension récupère les données via l'API HelloAsso et les écrit dans votre Google Sheets.

    4. Actualisez quand vous le souhaitez

      Relancez un import pour mettre à jour votre feuille sans dupliquer les données déjà présentes.
