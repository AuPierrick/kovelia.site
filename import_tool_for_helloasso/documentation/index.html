    Guide d'utilisation d'Import Tool for HelloAsso

    Dernière mise à jour : 22/08/2026

    Installation

    L'extension s'installe depuis le Google Workspace Marketplace, directement dans un Google Sheets. Une fois installée, elle apparaît dans le menu Extensions de votre feuille de calcul.

    Un compte Google disposant d'un accès à Google Sheets est nécessaire pour installer et utiliser l'extension.

    Connexion à HelloAsso

    Pour importer vos données, l'extension doit s'authentifier auprès de l'API HelloAsso à l'aide d'un Client ID et d'un Client Secret, propres à votre organisation.

    • Ces identifiants se créent depuis votre espace HelloAsso, dans les paramètres liés à l'API.
    • Ils sont ensuite renseignés une seule fois dans le panneau de configuration de l'extension.
    • Les identifiants sensibles ne sont jamais affichés dans la feuille ni dans les journaux d'import.

    Lancer un import

    Depuis le menu de l'extension, sélectionnez le ou les formulaires HelloAsso à importer, puis le type de données souhaité (inscriptions, paiements, présences…). L'extension récupère les données via l'API et les écrit, transformées et mises en forme, dans la feuille active.

    Actualiser une feuille

    Une feuille déjà importée peut être actualisée à tout moment : l'extension applique les mêmes paramètres que lors du premier import, sans dupliquer les lignes déjà présentes.

    Import des présences

    Un mode dédié permet de comparer les inscriptions à un formulaire avec les présences réellement constatées, pour faciliter le suivi d'un événement.

    Journaux d'exécution

    Chaque import génère un journal consultable depuis l'extension, indiquant les opérations effectuées et les éventuelles erreurs rencontrées, ce qui facilite le diagnostic en cas de problème.

    Dépannage

    En cas de difficulté (import incomplet, identifiants refusés, formulaire introuvable…), vérifiez d'abord la validité de vos identifiants HelloAsso et vos droits sur l'organisation concernée. Si le problème persiste, la page Contact / Support permet de signaler un dysfonctionnement.
