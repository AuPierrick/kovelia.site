    Gratuit · Extension Google Sheets

    Vos données de formulaires HelloAsso, importées et nettoyées dans Google Sheets.

    Import Tool for HelloAsso importe, nettoie et met en forme les données d'enregistrement de vos formulaires HelloAsso directement dans votre feuille de calcul — sans export manuel, sans copier-coller.

    Voir la documentation Une question ? Contactez-moi

    ✨ Les principaux atouts

    Pensé pour un usage réel, en association

    Multi-connexions API

    Gérez plusieurs connexions API correspondant à différents comptes associatifs HelloAsso.

    Automatisation des paramètres d'import

    Sauvegardez les paramètres de nettoyage et de mise en forme des données par association, type d'import et type de formulaire.

    Travail collaboratif

    Si le Google Sheets est partagé, les paramètres de connexion API HelloAsso et les paramètres d'import peuvent être partagés avec les autres utilisateurs.

    Fonctionnement

    Comment ça fonctionne ?

    Une fois installée, Import Tool for HelloAsso donne accès à plusieurs outils via le menu des extensions de Google Sheets. Ouvrez ou rechargez votre feuille, puis allez dans Extensions → Import Tool for HelloAsso pour accéder aux différents outils.

    Au premier lancement d'un des outils, il vous faudra accepter les 3 autorisations demandées par une fenêtre Google — c'est nécessaire au bon fonctionnement de l'extension.

    1. 🔑 Paramètres Connexion

      Permet d'établir, tester et partager plusieurs connexions API HelloAsso.

      • Une seule connexion API HelloAsso peut être active par Google Sheets.
      • La connexion active peut être changée à tout moment via cet outil.
    2. Connexion API HelloAsso active requise

      📥 Import Formulaires

      Permet de rechercher et sélectionner un ou plusieurs formulaires, de paramétrer et de lancer l'import.

      • Sélection d'un type d'import préparamétré.
      • Personnalisation des paramètres d'import (nettoyage et mise en forme).
      • Sauvegarde des paramètres d'import personnalisés par association, type d'import et type de formulaire.
    3. Connexion API HelloAsso active requise

      🔃 Actualisation Feuille active

      Permet de mettre à jour les données d'un formulaire déjà importé en utilisant les paramètres de nettoyage et de mise en forme précédemment définis. Pour cela, il suffit d'aller sur le tableau à actualiser et de lancer l'outil.

      ⚠️ Important : pour le bon fonctionnement de l'outil, ne modifiez pas manuellement les noms des feuilles et les noms des colonnes directement dans Google Sheets.

    4. 📋 Import Présences

      Permet d'importer dans un formulaire les présences récoltées via l'application mobile HelloAsso Scan, en utilisant son extraction CSV. Plus de détails sont disponibles dans la Documentation.
