    Présentation du service

    Import Tool for HelloAsso est une extension indépendante pour Google Sheets permettant notamment de récupérer des données disponibles via l'API HelloAsso et de les importer, transformer et organiser dans une feuille Google Sheets.

    L'extension peut notamment permettre :

    • l'import de données issues de formulaires HelloAsso ;
    • l'actualisation de données déjà importées ;
    • la transformation et la mise en forme des données ;
    • l'import de données relatives aux présences ;
    • la consultation de journaux d'exécution ;
    • la sélection et le filtrage des formulaires disponibles.

    Les fonctionnalités proposées peuvent évoluer au fil des versions de l'application.

    Conditions préalables

    L'utilisation de l'extension nécessite :

    Compte Google — Un compte Google disposant d'un accès à Google Sheets est nécessaire pour installer et utiliser l'extension. L'extension fonctionne dans l'environnement Google Workspace / Google Sheets et nécessite les autorisations Google présentées lors de son installation.

    Compte HelloAsso — Pour paramétrer une connexion API HelloAsso, l'utilisateur doit disposer d'un compte HelloAsso associé à une organisation ou une association et disposer des droits nécessaires pour créer et utiliser les identifiants d'accès à l'API HelloAsso. La configuration de la connexion à l'API nécessite notamment un Client ID et un Client Secret HelloAsso.

    L'utilisateur est responsable de la validité de ces informations d'identification et des droits associés au compte HelloAsso utilisé.

    Utilisation de l'API HelloAsso

    L'extension utilise l'API mise à disposition par HelloAsso afin de récupérer les données demandées par l'utilisateur.

    L'utilisation de l'API HelloAsso reste soumise aux conditions, limitations, règles techniques et politiques applicables définies par HelloAsso.

    Import Tool for HelloAsso est un outil indépendant et n'est pas un produit officiel de HelloAsso.

    L'éditeur de l'extension ne peut garantir la disponibilité permanente, les performances ou la compatibilité future de l'API HelloAsso.

    Une modification, interruption ou restriction de l'API HelloAsso peut entraîner une modification ou une interruption du fonctionnement de certaines fonctionnalités de l'extension.

    Autorisations Google

    Lors de son installation, l'extension demande certaines autorisations Google nécessaires à son fonctionnement. Ces autorisations peuvent notamment permettre à l'application :

    • d'interagir avec le Google Sheets dans lequel elle est installée ;
    • d'afficher son interface utilisateur ;

    L'utilisateur doit accepter les autorisations demandées afin de pouvoir utiliser les fonctionnalités correspondantes. L'extension ne demande que les autorisations nécessaires à son fonctionnement.
